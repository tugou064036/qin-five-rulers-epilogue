# 尾声 · 我到底是谁（课程结尾互动页）

接在动画 “我” 的内心 OS ——「所以这一次，我到底是谁呢」之后，向学生揭示：这一课代入的不是一个人，而是秦国前后五位君主接力做成的事。

## 打开方式
直接用浏览器打开 `index.html` 即可。六张人物立绘、青铜序号牌和功绩印章均已嵌入网页，单独发送这个 HTML 文件就能离线查看。也可以上传到静态托管。

## 流程
1. **衔接动画**：中央只有一道逆光剪影，对话框出现「心声」，台词逐字打出“所以这一次，我到底是谁呢？”，点击继续（右下角可跳过片头）。
2. **一分为五**：画面中央的「我」化作五道剪影，沿时间线散开，标题揭示“你代入的，并不是一个人。”
3. **悬停探索**（核心需求）：五位君主以剪影并排。鼠标移到哪一位，哪一位才放大并显出完整立绘，移开后恢复剪影；对话框逐字播放他的功绩“我做的是——……”。
4. **揭晓**：五位都听完后出现「揭晓答案」，五枚功绩印章依次盖下，给出总结。

## 交互细节
- 悬停带 40–110ms 意图延迟，鼠标快速扫过时不会频繁闪动；鼠标移到对话框里阅读时，保留当前台词，人物恢复剪影，点击对话框可直接显示全文。
- 触屏：点按立绘激活，点空白处收起。键盘：Tab 聚焦，←/→ 切换，Esc 收起。
- 顶部进度显示已聆听几位（台词播完才算听过），听完的人物，其名牌上的青铜圆章中心变为朱红。
- 时间线标注相邻两位之间隔了几代：中隔四君、中隔七君、父子相继。
- 音效：每位君主对应一个五声音阶的钟声（WebAudio 合成，无音频文件），可关闭。如果系统装有中文语音，会多出一个「朗读」开关（浏览器 TTS，默认关闭）。
- 支持 `prefers-reduced-motion`；16:9 舞台按窗口等比缩放（与 demo 一致），竖屏手机会提示横屏。

## 修改与替换
所有文案集中在 `index.html` 脚本开头的 `MONARCHS` / `GAPS` / `COPY` 里。
- 如需换图，可把对应君主的 `img` 改为本地图片路径（例如 `"portraits/fei.webp"`）。使用外部路径后，请连同图片一起交付。建议使用透明底全身立绘，脚底对齐画面下沿。
- **接配音**：在 `showSpeech()` 里把 `Voice.say(...)` 换成播放对应的 mp3 即可。

## 说明
- 题目中的“秦共工”应为 **秦共公**（康公之子，前608—前604年在位），页面里用的是秦共公。
- 开场的「我」与五位君主各有一张 AI 生成的课程人物插画。人物相貌及服饰细节为艺术想象。
- 功绩文案依据《史记·秦本纪》，秦共公一条依据《左传·宣公二年》，对话框右上角标了出处。
